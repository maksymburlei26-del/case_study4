**Іменники** (усі з брифу): місто, станція, велосипед, номер, клієнт, ім'я, баланс, рахунок, кількість, хвилина, грн, адміністратор, мережа

-

**Дієслова** (усі з брифу): є, стоять, буває, має, взяти, покататись, повернути, коштує, списуються, хоче, бачити, заробила

-

**Рішення щодо іменників:** 

| Іменник | Клас / атрибут / не потрібен | Чому |
| станцiя велосипед клiент---|клас---|-станція тому що має список велосипедів на ній велосипед бо має тип та номер клієнт має імя та баланс--|
|номер тип iмя баланс  | атрибут | номер для велосипеда тип звичайний або електричний імя клієнта і баланс клієнта |

**Рішення щодо дієслів:**

| Дієслово | Кому належить (клас або окрема функція) |
|взяти, повернути,  |-функції поїздки--|
|стоять, є,  |наявність на станції велосипедів |
|списуються|гроші знімаються з балансу |
|коштує|порахувати вартість|
